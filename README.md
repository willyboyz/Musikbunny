# Mini Musik

Pemutar musik Android sederhana untuk file audio lokal.

Fitur: pilih lagu melalui pemilih file Android, putar, jeda, lanjutkan, stop, dan seek.

## Build lewat GitHub
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder proyek ini ke root repository.
3. Buka tab Actions dan jalankan workflow **Build Mini Musik APK**.
4. Setelah selesai, buka hasil workflow dan unduh artifact **Mini-Musik-debug**.
5. Ekstrak ZIP artifact untuk mendapatkan `app-debug.apk`.

APK ini untuk pengujian pribadi. Belum mendukung playlist, pemutaran latar belakang, atau pemindaian koleksi otomatis.
